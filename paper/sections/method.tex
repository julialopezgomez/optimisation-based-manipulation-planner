The planner has an offline stage, which depends only on the robot, the object
and the scene, and an online stage that is run for each query. Offline, it
builds the free sets (Section~\ref{sec:method:free}) and the grasp set
(Section~\ref{sec:method:grasp}), and intersects them into validated
transition sets and a graph, using only linear programs
(Section~\ref{sec:method:graph}). Online, the reachability A* chooses the
sequence of sets and grasps (Section~\ref{sec:method:search}), and a second
stage turns it into motions (Section~\ref{sec:method:recovery}).
Fig.~\ref{fig:reach} illustrates the online stage. New goals and start
configurations reuse the offline stage unchanged.

\subsection{Free sets}
\label{sec:method:free}
We inner-approximate $\CSfree$ by polytopes $P_j=\{q:A_jq\le b_j\}$,
$j=1,\dots,J$, computed with clique covers of visibility
graphs~\cite{werner2024approximating} and IRIS-NP2
regions~\cite{werner2024faster} in Drake~\cite{tedrake2019drake}. By
Assumption~\ref{ass:task}(iii), the object coordinate does not affect
collisions. We therefore replace each region by its slice at $\alpha=0$,
$F_j=\{x:(x,0)\in P_j\}$. This is sound: if $(x,0)$ is collision-free, so is
$(x,\alpha)$ for every $\alpha$. The robot can then occupy any $x\in F_j$ at
any object angle, and the planner tracks $\alpha$ separately.

\subsection{Grasp set}
\label{sec:method:grasp}
For a 7-DOF arm, a grasp constrains the pose of the hand frame $E$ relative to
the cap frame $C$, a nonlinear function of the arm joints. The hand must be
centred above the cap, within a height band, with its approach axis
$z_E={}^{C}R^{E}(x)\,e_z$ pointing down:
\begin{align}
  h(x) &= [\,p_x,\; p_y,\; z_{E,x},\; z_{E,y}\,]^\top = 0, \label{eq:grasp_h}\\
  g(x) &= [\,p_z - z_{\max},\; z_{\min} - p_z,\; z_{E,z} + c\,]^\top \le 0, \label{eq:grasp_g}
\end{align}
with $p={}^{C}p^{E}(x)$, $[z_{\min},z_{\max}]=[0.105,0.110]$\,m and $c=0.9$.
The fingers are restricted to a 1\,mm band around the width of the cap. The
set $\{h=0,\,g\le0\}$ is thin and curved, so it cannot be written as a
polytope. We approximate it locally, using two ideas from NLP
sampling~\cite{toussaint2024nlp}. First, a seed grasp $x_0$ is found by
Gauss--Newton minimisation of the constraint violation
$\|[h(x);\max(g(x),0)]\|^2$ from a random start. Second, the directions that
preserve the grasp to first order are the null space of the Jacobian $J_h$ of
the equality constraints, which NLP sampling uses to move along constraint
manifolds. The grasp set keeps the configurations that stay within $\epsilon$
of this null space, around $x_0$:
\begin{equation}
\begin{aligned}
G=\{x:\ & |h_0+J_h(x-x_0)|\le\epsilon,\ \ g_0+J_g(x-x_0)\le\epsilon,\\
        & x^{G}_{\min}\le x\le x^{G}_{\max},\ \ |x_j-x_{0,j}|\le\rho\ \ \forall j\in\mathcal{A}\},
\end{aligned}
\label{eq:graspPoly}
\end{equation}
where $h_0,J_h,g_0,J_g$ are evaluated at $x_0$, $\epsilon=10^{-3}$, and
$\mathcal{A}$ are the arm joints other than the wrist.

Two properties of the task shape this set. First, the wrist axis passes
through the origin of $E$ along $z_E$, so rotating the wrist changes neither
$p$ nor $z_E$. The grasp constraints are therefore \emph{exactly} invariant
along $w$, which we verified to machine precision over the whole wrist range,
and $G$ spans the full wrist range. Second, $J_h$ has rank 4, so the null
space has 6 dimensions, and without the trust region $\rho$ in
\eqref{eq:graspPoly} it would only be bounded by the joint limits. Far from
$x_0$, the linearisation is meaningless: without the trust region, the
extreme points used by the graph moved an arm joint by 2.27\,rad from $x_0$,
with $\|h\|_\infty=0.95$ and the hand 0.80\,m away from the cap. With
$\rho=0.05$\,rad, $\|h\|_\infty$ stays around $2\times10^{-3}$ along our plans
\tocheck{numbers from the guide's q0 run}. Seeds on other parts of the grasp
manifold give further grasp sets that the search treats in the same way. We
use a single seed in this paper (see Section~\ref{sec:discussion}).

\subsection{Transition sets and the graph}
\label{sec:method:graph}
For every free set with $F_k\cap G\ne\emptyset$, we form the transition set
$T_k=G\cap F_k$. Two LPs give its extreme wrist values
$w_k^{\pm}=\max/\min\{\pm w: x\in T_k\}$ and points $x_k^{\pm}\in T_k$
attaining them. A stroke inside $T_k$ turns the object by at most
$L_k=w_k^+-w_k^-$, and we discard sets with $L_k<\Lmin$. Since $G$ is thin in
every direction but the wrist, a transition set is essentially a wrist
interval, and by convexity the segment $[x_k^-,x_k^+]$ lies in $T_k$.

\paragraph{Validation} The free sets are collision-free only in a volume
sense: IRIS-NP2 bounds the fraction of each region's volume in
collision~\cite{werner2024faster}. A transition set has almost no volume, so
it can be entirely in collision without violating that bound, and it lies
exactly where the hand is closest to the object and the obstacles. We
therefore validate each $T_k$ separately. Since $T_k$ is essentially a
segment, we check densely spaced configurations on $[x_k^-,x_k^+]$ with a
collision checker, and replace $T_k$ by the sub-intervals of the wrist on
which every check passes. Each of these is $T_k$ intersected with a bound on
$w$, and is therefore still a polytope. \todo{implement (E5); state the check
resolution; this is a dense check, not a certificate. Certifying these thin
sets with C-IRIS~\cite{dai2024certified} is an alternative.}

\paragraph{Graph} The graph has two kinds of edges. A \emph{transit} edge
joins $F_i$ and $F_j$ if they intersect, and its door point is the Chebyshev
centre of $F_i\cap F_j$. A \emph{switch} edge joins $F_i$ and $T_k$ if they
intersect. For it, we store the wrist range $[a_{ik}^-,a_{ik}^+]$ of
$F_i\cap T_k$ and the points attaining its ends. Each of these quantities is
an LP feasibility check, a Chebyshev centre or an extreme point. No integer
variables or vertex enumeration are needed, and the number of LPs is
$O(J^2+JK)$ for $J$ free sets and $K$ transition sets.

\subsection{Reachability A*}
\label{sec:method:search}
\paragraph{Nodes} As in CASSR~\cite{wang2026cassr}, a node does not represent
a configuration but a set reachable from the start. A \emph{free node}
$(F_i,[\alo,\ahi])$ states that every $x\in F_i$ is reachable together with
every $\alpha\in[\alo,\ahi]$. Since $F_i$ is convex and $\alpha$ is constant
during transit, any point of $F_i$ can be reached from any other along a
straight line. A \emph{transition node} $(T_k,[\alo,\ahi],\phi,[a^-,a^+])$
also records the wrist range $[a^-,a^+]$ through which the set was entered,
and a phase $\phi$: \emph{entered} (in the set, not yet grasping),
\emph{holding} (just completed a stroke) or \emph{released} (just completed a
return, with the wrist back at $w_k^-$). The interval carries all the
information about the path so far. For example, reaching $F_3$ before any
grasp and after a stroke of 2\,rad gives the same set with the intervals
$\{3\}$ and $[1,3]$, which are two different nodes.

\paragraph{Moves and costs} Table~\ref{tab:moves} lists the successors of a
node. Only strokes widen the interval. A stroke can turn the object by any
amount up to its maximum, so it lowers $\alo$ and keeps $\ahi$. Since the
object can only be grasped inside transition sets, these are the only sets
where reachability grows in $\alpha$. Leaving a transition set towards $F_j$
can also force some turning. Inside $T_k$, the wrist only moves forward while
grasping, so reaching the exit range from the entry range turns the object by
at least $d=\max(0,a_{jk}^- - a^+)$, which lowers $\ahi$. We clip $\alo$ at
$\max(\agoal,\alpha_{\min})$. Strokes, returns and releases cost 1 each, and
every other move costs $\mu\ll1$ ($\mu=10^{-3}$). Every stroke is followed by
exactly one return or release, so the cost of a plan is twice its number of
grasps, plus $\mu$ times its number of set changes. Minimising the cost
therefore minimises the number of grasps first and the set changes second.
Releasing must cost 1, otherwise leaving and re-entering a transition set
would be a cheaper substitute for a return.

1, before any grasp; such a move should cost $\mu$ for the cost to be exactly

\paragraph{Heuristic, goal and dominance} With $\Lmax=\max_k L_k$, the
heuristic
\begin{equation}
  h(\nu)=2\Big\lceil\frac{\alo-\agoal}{\Lmax}\Big\rceil+\mathbf{1}[\phi=\text{holding}]
  \label{eq:heuristic}
\end{equation}
is admissible: each remaining stroke turns the object by at most $\Lmax$ and
is followed by a return or the final release, and a holding node must still
release. It is also consistent, since no move lowers $h$ by more than its
cost. A free node is a goal if $\xgoal\in F_i$ and $\agoal\in[\alo,\ahi]$. A
node is \emph{dominated}, and skipped, if an expanded node with the same key
has an interval that contains its interval at no higher cost. The key is the
set for free nodes, and the set, phase and entry range for transition nodes.
Because the key and the interval describe everything that can still be
reached from a node, this check is exact. Algorithm~\ref{alg:astar}
summarises the search.

\begin{algorithm}[t]
\caption{Reachability A*}
\label{alg:astar}
\begin{algorithmic}[1]
\Input graph of Sec.~\ref{sec:method:graph}; $(\xinit,\ainit)$, $(\xgoal,\agoal)$
\Output sequence of sets and grasp actions, or \textsc{none}
\State $\mathcal{O}\gets\{(F_i,[\ainit,\ainit]) : \xinit\in F_i\}$;\ \ $\mathcal{E}\gets\emptyset$
\While{$\mathcal{O}\neq\emptyset$}
  \State $\nu\gets\arg\min_{\nu\in\mathcal{O}} g(\nu)+h(\nu)$; remove $\nu$ from $\mathcal{O}$
  \If{$\nu$ dominated by $\mathcal{E}$} \textbf{continue} \EndIf
  \State $\mathcal{E}\gets\mathcal{E}\cup\{\nu\}$
  \If{$\nu=(F_i,[\alo,\ahi])$, $\xgoal\in F_i$, $\agoal\in[\alo,\ahi]$}
    \State \Return path to $\nu$
  \EndIf
  \For{each successor $\nu'$ of $\nu$ (Table~\ref{tab:moves})}
    \If{$\nu'$ not dominated by $\mathcal{E}$} add $\nu'$ to $\mathcal{O}$ \EndIf
  \EndFor
\EndWhile
\State \Return \textsc{none} \Comment{no plan within the sets}
\end{algorithmic}
\end{algorithm}

\subsection{From sets to motions}
\label{sec:method:recovery}
The search fixes the sets and the grasp actions, for example \emph{enter,
stroke, return, stroke, release}. As in CASSR, a second stage computes the
configurations, here without a solver. A backward pass from $\agoal$ first
decides how much each visit to a transition set turns the object, within the
maximum turn of each of its strokes. It ends exactly at $\ainit$, because the
search proved $\agoal$ reachable. Waypoints are then placed at the door points
for transit, at points of $F_i\cap T_k$ for entering and leaving, and on the
segment $[x_k^-,x_k^+]$ for strokes and returns. Each motion between two
waypoints is a straight line, and we record a set, $F_j$ or $T_k$, that
contains both of its ends. By convexity, that set contains the whole motion.
We check this containment and the coupling ($\Delta\alpha=-\Delta w$ on
strokes, $\Delta\alpha=0$ otherwise) for every motion. Path length is not
optimised. Since the sequence of sets is fixed, a convex program over these
sets, e.g., GCS~\cite{marcucci2023motion} restricted to them, could shorten
the path. \todo{implement, or keep as future work.}

\subsection{Properties}
\label{sec:method:properties}
\begin{proposition}[informal]
\label{prop:guarantees}
Relative to the free sets $\{F_j\}$ and the transition sets $\{T_k\}$:
(i) every motion returned is a straight line inside one set that satisfies
the coupling of Assumption~\ref{ass:task}, so the path is collision-free
whenever the sets are;
(ii) the search terminates. If a plan exists whose transit motions lie in the
free sets and whose strokes lie in the transition sets, it returns one with
the minimum number of grasps, with ties broken by the number of set changes.
Otherwise, it returns \textsc{none};
(iii) the second stage succeeds on every sequence the search returns.
\end{proposition}
\noindent\emph{Sketch.} (i) follows from convexity of the recorded sets.
(ii) Each stroke lowers $\alo$ by at least $\Lmin$ until it reaches $\agoal$,
so finitely many intervals arise per key, and the search terminates. With a
consistent heuristic and exact dominance, A* expands a goal node of minimum
cost first~\cite{hart1968astar}. Entering at the highest wrist value and
leaving at the lowest wrist value of each switch edge minimises forced
turning, so restricting entries and exits to these points loses no plan.
(iii) The backward pass mirrors the interval updates of
Table~\ref{tab:moves}. \tocheck{write the full proof; (iii) is asserted in our
implementation but not yet proven. Overlapping transition sets would need
chain-aware placement, so each set is its own segment for now.}
\hfill$\square$

These guarantees are relative: a plan reported as optimal uses the fewest
grasps \emph{that the sets allow}. This is why the transition sets must be
validated (Section~\ref{sec:results:fidelity}).

\subsection{Relation to a mixed-integer formulation}
\label{sec:method:miqp}
Our earlier planner~\cite{lopezgomez2025minf} posed the same problem as an
MIQP. For a fixed number of grasps $\ell$, it chose keyframes
$\qinit,x_1,\dots,x_{2\ell},\qgoal$, with binary variables for the set
containing each keyframe and big-M constraints $A_jx_i\le b_j+M(1-z_{ij})$,
and solved for $\ell=1,2,\dots$ until feasible. This works on 3- and 4-DOF
tasks. On the 10-DOF task, the grasp set is $2\epsilon=2\times10^{-3}$ thick,
whereas with $M=10^6$ and MOSEK's default integrality tolerance of
$10^{-5}$~\cite{mosek}, a binary accepted as 1 may relax its constraints by
$M\cdot10^{-5}=10$\,rad, more than any joint range. Tight big-M constants or
convex-hull formulations~\cite{vielma2015mixed} would mitigate this at the
cost of a larger model, but the number of grasps would still be fixed by an
outer loop. \tocheck{record the MOSEK status/log for the 10-DOF MIQP failure.}
