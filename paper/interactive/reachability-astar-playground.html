Why the entry range matters

A stroke can only drive the wrist forward as far as the set allows, counted from where you came in. Enter T0 low and the first stroke is long; enter high and it is short.

enter froma−first stroke c = w+ − a−

After a return the wrist is back at w−, so from then on a stroke gets the whole range, c = Lk.

The one that trips people up. The entry range is not the wrist range of the transition set, and it is not recoverable from the interval. It records which doorway you came through, which is what decides how long the first stroke can be, and how much turning is forced when you leave.

      Where this differs from the notebook

      Return from entered. Algorithm 2 as written in the paper allows a return only from holding (line 12). full_arm_planner.ipynb also allows it from entered, at cost 1, before any grasp has happened. This tool follows the paper. If the notebook is right, the cost of a plan is no longer exactly twice the number of grasps.
      Forced turning after a stroke. d is measured from a+, the top of the entry range. After a stroke the wrist has already moved, so a+ is not where the wrist is. The value is conservative, never optimistic, but it can refuse exits that are actually reachable.
