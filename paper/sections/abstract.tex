\begin{abstract}
Manipulation planning has to decide where a robot takes hold of an object and
where it lets go, how many times, and how to move in between. The number of
contacts is not known before planning, and the configurations in which a grasp
is possible form thin, nonlinear sets, so planners either enumerate a finite
set of grasps, and can then only find the solutions that set contains, or keep
the grasps continuous inside a mixed-integer programme, which has to be told
how many grasps to look for. We present a planner that expands convex sets of
grasping configurations within an A* search. Intersecting a convex
decomposition of the collision-free space of robot and object with a convex
model of the grasp constraints yields the sets in which the robot can take
hold of the object, move it and let go, and the search carries with each set
the object configurations it makes reachable. It needs no bound on the number
of grasps, builds its graph from linear programs alone, and returns a plan
with the fewest grasps its sets allow, or establishes that none exists. A
second stage recovers the motions without an optimiser.
