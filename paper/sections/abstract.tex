\begin{abstract}
Many manipulation tasks need a sequence of grasps whose length is not known
in advance. Turning a cap with a wrist of limited range takes as many regrasps
as the goal, the kinematics and the obstacles require. We cast multi-regrasp
planning as a reachability problem over a convex decomposition of the
collision-free configuration space of robot and object. Grasp pieces, the
polytopes where the robot can hold the object, are the only sets where the
object moves. Inspired by recent footstep planners, we search them with an A*
whose nodes are not configurations but polytopes paired with the set of object
configurations reachable inside them. When one object coordinate is coupled to
one robot joint, this set is an interval, so reachability propagates by
interval arithmetic and dominance is exact. The graph is built with linear
programs only, and the search returns a plan with the minimum number of grasp
actions relative to the decomposition, with no integer variables and no fixed
horizon. On a 10-DOF cap-turning task with a Franka Panda, where a
mixed-integer formulation is numerically unreliable, it plans in 4\,ms. The
same task shows that probabilistically certified decompositions can contain
collisions concentrated on the grasp sets where regrasps happen. This makes the
fidelity of these switch sets, not coverage of free space, the key requirement
for planners of this kind.
