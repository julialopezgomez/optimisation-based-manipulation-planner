\section{All runs of the GCS comparison}
\label{app:gcs}
Table~\ref{tab:gcs:all} lists every run of the comparison of
Section~\ref{sec:results:gcs}, including the runs that failed or ran out of
memory. All of them use T2, with the transition sets validated as in
Section~\ref{sec:results:gcs} ($\Lmax=0.81$\,rad).
\begin{itemize}
  \item \emph{Start and goal.} Each run draws its own start and goal from a
    randomly seeded grasp, so rows can be compared within a run but not across
    runs.
  \item \emph{Run~A} is the run of Tables~\ref{tab:gcs}
    and~\ref{tab:gcs:scaling}. It saved its start, goal and sets, and
    reproduces exactly.
  \item \emph{Runs~B--E} are earlier runs. Their footnotes give what their time
    and memory measure.
  \item \emph{Pruning.} Unless stated otherwise, the free sets kept in each copy
    of the graph are as follows. The between layers keep the 8 free sets that
    meet a transition set. The approach and depart layers keep those, the free
    sets that contain the start or the goal, and the free sets of the A*'s
    plan. Only detours through free sets that touch none of these are lost.
\end{itemize}
In Run~D the full GCS paths are much shorter than the A*'s (e.g.\ 6.30
against 19.13). That run has no row for GCS on the A* sequence, so it does not
tell whether GCS chose different sets or only placed the configurations
better. In Runs A--C, where both ran, the full GCS chose the A*'s sets.
